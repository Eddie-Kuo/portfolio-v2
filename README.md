# Eddie Kuo — Portfolio (v2)

A single-page personal site: intro, work history, and featured projects. Built with **Next.js 14** (App Router), **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Copy and media live under `constants/` and `assets/`.

```bash
npm install && npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Production build: `npm run build` then `npm start`.

Design nods to [Brittany Chiang](https://brittanychiang.com/) and [Miraya Tech](https://www.instagram.com/mirayatech/) (credited on the site).
